# Release Gate

Pre-release checks:

```
[ ] Quality Gate passes       — all 11 checks
[ ] Security Gate passes      — all 6 checks
[ ] Version bump              — semver applied
[ ] CHANGELOG updated         — accurate since last release
[ ] Documentation current     — README, API docs up to date
[ ] Tag created               — git tag <version>
[ ] Release summary written   — what changed, why, migration notes
```

Only the Release Manager may approve a release.
