# Protocol: Plan

**Phase:** 2 of the engineering cycle

## Steps

1. Read `.constitution/MISSION.md` — align with mission.
2. Read `.constitution/SUCCESS.md` — pick the next incomplete checkbox.
3. Break the checkbox into concrete implementation steps.
4. Estimate complexity (small / medium / large).
5. Write `.memory/NEXT_ACTION.md` with the single next step.

## Rules

- Never plan more than one cycle ahead.
- If no checkbox remains, stop (mission complete).
- If confidence < 80%, escalate to Researcher role first.

## Output

- `.memory/NEXT_ACTION.md` updated
- Task added to `.memory/TASK_QUEUE.json`
