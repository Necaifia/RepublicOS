# Protocol: Review

**Phase:** 4 of the engineering cycle

## Steps

1. Read the full diff of the cycle.
2. Check for logic errors, edge cases, and security issues.
3. Verify tests cover the changes.
4. Verify no secrets or credentials in the diff.
5. Approve or request changes.

## Authority

The Reviewer role has authority to block. If the Reviewer blocks, return to Implement.

## Output

- Approval or detailed rejection reason
