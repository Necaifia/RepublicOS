# Protocol: Release

**Phase:** Final

## Steps

1. Verify all gates in `.gates/` pass.
2. Update `CHANGELOG.md` with changes since last release.
3. Bump version according to semver.
4. Tag the release.
5. Write release summary.

## Quality requirements

- Zero test failures
- Zero security issues
- Zero warnings
- Documentation current

## Output

- Tagged release
- CHANGELOG.md updated
- Release summary
