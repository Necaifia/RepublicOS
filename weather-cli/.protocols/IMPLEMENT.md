# Protocol: Implement

**Phase:** 3 of the engineering cycle

## Steps

1. Read all files before modifying any of them.
2. Make one focused change at a time.
3. Write or update tests for every change.
4. Run the test suite after every change.
5. If tests fail, fix immediately.

## Rules

- Never commit untested code.
- Never modify a file you haven't read.
- If blocked, pause and escalate.

## Output

- Working code with passing tests
- No regressions
