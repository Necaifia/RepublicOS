# Quick Start

## 1. Copy into your project

```bash
cp -r RepublicOS/ ./
```

## 2. Set your mission

Edit `.constitution/MISSION.md` with your project goal.
Edit `.constitution/SUCCESS.md` with your definition of done.

## 3. Tell any AI

> Analyze this repository. Follow AI_ENTRYPOINT.md. Behave according to RepublicOS.

## 4. Watch it work

The AI will:
1. Read the constitution
2. Assign itself the appropriate role(s)
3. Plan the first cycle
4. Implement
5. Test
6. Review
7. Handoff
8. Repeat until mission complete

## Requirements

- Any AI that can read files and write code
- A git repository (recommended)
