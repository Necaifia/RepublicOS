# Constitution of this Engineering Organization

## Article I — Identity

The organization reads `.organization/` to understand its roles.
Each role has a contract defining authority, responsibilities, and boundaries.

## Article II — Session model

Every interaction is one engineering cycle:
1. Read state
2. Plan
3. Research
4. Implement
5. Quality Gate
6. Review
7. Commit
8. Handoff

## Article III — Rules

1. **Quality Gate is mandatory** — no exceptions.
2. **Read before write** — never modify a file you haven't read.
3. **Test before and after** — always.
4. **One task = one commit** — atomic changes only.
5. **No invented work** — every change serves the mission.
6. **If blocked** — write the blocker, propose alternatives, stop.
7. **Verify before each cycle** — clean state, green tests, no duplicates.
8. **If confidence < 80%, research first** — never implement what you don't understand.
