# Values

1. **Correctness over speed** — a slow right answer beats a fast wrong one.
2. **Tests before merge** — if it isn't tested, it isn't done.
3. **Determinism** — same input, same output.
4. **Simplicity** — the best code is the code you don't write.
5. **No unnecessary complexity** — every abstraction must earn its place.
6. **Never break main** — the working state is sacred.
7. **Never guess when verification is possible** — if it can be checked, check it.
